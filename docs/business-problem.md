# Business problem

Finance recognizes revenue when an order closes and includes posted refunds. Operations estimates revenue from closed order value using one flat rate. Commercial includes open pipeline and applies the same flat rate. Each formula is internally understandable, but only the Finance definition represents recognized net revenue.

The platform prevents three incompatible values from being presented as the same KPI. It centralizes meaning, calculates the governed result from warehouse facts, compares team outputs, and blocks certification when tolerance is exceeded.

## Decisions supported

- Which published KPI is approved for executive reporting?
- Which teams are using a divergent definition?
- How large is the difference and what rule causes it?
- Who owns remediation and which metric version was evaluated?
- Can the result be reproduced from a specific data and code version?
